### **СТРАТЕГИЯ ОБХОДА ДЛЯ LINUX MINT (бесплатно):**

**1. Первый и самый простой вариант — DNSCrypt-Proxy + DoH (DNS-over-HTTPS).**
Он шифрует DNS-запросы, но не весь трафик. Может помочь, если блокировка на уровне DNS. Уже частично есть в системе.

**2. Второй вариант — хороший, но требует сервера за пределами РФ (бесплатный хостинг).**
*   **Outline** (от Jigsaw) — создаёт свой VPN-сервер на любом VPS. Есть бесплатные тарифы у Oracle Cloud, Google Cloud.
*   **WireGuard** — легковесный, но его тоже научились выявлять.

**3. Третий вариант (наиболее подходящий под запрос «zapret/goodbyedpi» для Linux) — это инструменты, использующие методы обфускации:**

**Пояснения:**
- `-thread_queue_size 512` — буфер для синхронизации потоков.
- `-video_size 1024x768` — разрешение экрана (можно уменьшить до 800x600).
- `-framerate 10` — 10 кадров/с (мало, но для Core 2 Duo нормально).
- `-i :0.0+0,0` — захват экрана с координатами (левого верхнего угла).
- `-f v4l2` — захват камеры.
- `-f alsa -ac 1 -i hw:1,0` — захват моно-аудио с гарнитуры (подставь свои card,device).
- `-filter_complex` — наложение камеры поверх экрана с прозрачностью (alpha=0.8).
- `-preset ultrafast -tune zerolatency` — минимальная загрузка CPU.
- `-record_time 60` — записать 60 секунд.

DeepSeek: **ПРИНЯТО. tpws запущен в SOCKS5-режиме на порту 1080.** Теперь нужно **настроить браузер** для использования этого прокси и **проверить доступность YouTube через браузер**, а не через curl, потому что curl может иметь особенности в работе с SOCKS5 и SSL.

### **Шаг 1: Проверяем, слушает ли tpws порт 1080.**
```bash
sudo netstat -tlnp | grep :1080
```
Если видишь `LISTEN` — процесс работает.

### **Шаг 2: Настраиваем Firefox (или другой браузер) на использование SOCKS5-прокси.**
1. Открой **Firefox**.
2. Перейди в **Настройки** → **Прокси-сервер** (или введите `about:preferences#general` в адресной строке и прокрутите до раздела «Прокси-сервер»).
3. Выбери **Ручная настройка прокси-сервера**.
4. В поле **SOCKS-хост** введи `127.0.0.1`, порт `1080`.
5. Выбери **SOCKS v5**.
6. Поставь галочку **«Использовать этот прокси-сервер для всех протоколов»**.
7. Нажми **OK** и перезагрузи браузер.

### **Шаг 3: Проверяем доступность YouTube в браузере.**
- Открой новую вкладку и перейди на `https://youtube.com`.

**Если YouTube не загружается:**
1. **Проверь IP-адрес** через прокси: открой `https://icanhazip.com` — он должен показать IP, отличный от твоего обычного (возможно, IPv6).
2. **Попробуй другие сайты** (`https://twitter.com`, `https://reddit.com`).
3. **Отключи в браузере IPv6** (если проблема с ним): в адресной строке набери `about:config`, прими риск, найдите `network.dns.disableIPv6` и установи значение `true`.

### **Шаг 4: Если YouTube всё ещё не работает, попробуем усилить обфускацию tpws.**
Остановим tpws и запустим с дополнительными параметрами:
```bash
sudo pkill tpws
sudo ./tpws --port 1080 --socks --hostcase --split-any --disorder --oob --hostdot --domcase --daemon
```
После запуска проверь YouTube в браузере снова.

### **Шаг 5: Резервный вариант — использование подключаемых транспортов.**
Если tpws не справляется с блокировкой YouTube, то нужен более мощный инструмент. Но для этого требуется **внешний сервер** и настройка **Shadowsocks/V2Ray с плагинами обфускации** (например, v2ray-plugin). Это уже следующая операция.
