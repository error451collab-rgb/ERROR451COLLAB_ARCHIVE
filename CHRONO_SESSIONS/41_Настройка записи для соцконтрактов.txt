### 🛠 **ДИАГНОСТИКА И РЕШЕНИЕ ДЛЯ APPLET**

**1. Проверка зависимостей и их состояний**

Аплет требует три пакета: `ffmpeg`, `xdotool`, `x11-utils`. Открой терминал и выполни команды **последовательно**:

```bash
# 1. Проверяем, установлены ли пакеты и их версии
dpkg -l | grep -E "ffmpeg|xdotool|x11-utils"

# 2. Если каких-то нет — устанавливаем
sudo apt update
sudo apt install ffmpeg xdotool x11-utils -y

# 3. Проверяем, не "сломан" ли ffmpeg (частая проблема в Mint)
ffmpeg -version
```
*Если в выводе последней команды будет ошибка (например, `ffmpeg: error while loading shared libraries`) — значит, ffmpeg требует переустановки.*

**2. Проверка прав на запись в папку сохранения**

Аплет по умолчанию сохраняет в `~/Videos`. Убедимся, что папка существует и права корректны:

```bash
# Проверяем наличие папки
ls -la ~/ | grep Videos

# Если нет — создаем
mkdir -p ~/Videos

# Даем права (на всякий случай)
chmod 755 ~/Videos
```

**3. Принудительная перезагрузка аплета**

Иногда аплет "зависает" в фоне. Выполни в терминале:

```bash
# Перезапускаем Cinnamon (не закрывает приложения, только оболочку)
cinnamon --replace &
```
*После этого снова попробуй запись через аплет.*

**4. Глубокая очистка и переустановка аплета**

Если предыдущие шаги не помогли, удалим и заново установим аплет:

```bash
# Удаляем аплет (через настройки или командой)
# Находим его в папке апплетов
ls ~/.local/share/cinnamon/applets/

# Удаляем папку апплета (имя может быть немного другим, но содержать tech71)
rm -rf ~/.local/share/cinnamon/applets/ScreenShot+RecordDesktop@tech71

# Перезагружаем Cinnamon (как выше)
cinnamon --replace &
```
Затем через **Параметры системы → Апплеты** заново установи его из репозитория.

### 🔊 **АЛЬТЕРНАТИВА: НАСТРОЙКА ЗАПИСИ ЗВУКА В SIMPLE SCREEN RECORDER (SSR)**

Поскольку SSR у тебя уже работает с видео, настроим звук с гарнитуры.

1. **Запусти SSR** → вкладка **«Аудиозапись»**.
2. **Источник звука:** Выбери не `PulseAudio Default` (который может вещать системный звук), а конкретное устройство — твою гарнитуру. Обычно называется `Analog Output` или `Headphones`.
3. **Проверь уровень громкости** в системе: нажми на иконку звука в панели → `Микшер` → убедись, что для устройства ввода (гарнитура) стоит достаточная громкость.
4. **Тест:** Сделай короткую запись с комментарием → воспроизведи через `vlc` или `mpv`.

*Если звук по-прежнему не записывается, возможно, нужно перенаправить аудиопоток. Установи `pavucontrol` и поэкспериментируй:*

```bash
sudo apt install pavucontrol -y
pavucontrol &
```
Во вкладке **«Запись»** во время записи в SSR попробуй сменить источник на `Монитор встроенного аудио` или аналогичный.

**ВАРИАНТ 2: Продвинутая настройка встроенного апплета (если принципиально)**

Встроенный аплет `ScreenShot+RecordDesktop` не поддерживает наложение камеры напрямую. Но есть обходной путь:

**Способ A: Использовать v4l2loopback для создания виртуальной камеры с наложением**
*(Сложно, требует настройки, но мощно)*

```bash
# Установка виртуальной камеры и утилит
sudo apt install v4l2loopback-dkms gstreamer-tools -y

# Загрузка модуля
sudo modprobe v4l2loopback exclusive_caps=1 max_buffers=2

# Проверка создания виртуальной камеры
ls -la /dev/video*  # Должен появиться новый videoX
```

Далее нужно настроить композицию через OBS или другой софт, который будет выводить картинку на виртуальную камеру, а аплет будет захватывать уже её. **Но это лишняя сложность.**

**Способ B: Простой скрипт для записи камеры отдельно (параллельная запись)**

```bash
# Установи необходимые утилиты
sudo apt install ffmpeg mplayer -y

# Запусти запись камеры в отдельном окне терминала
ffmpeg -f v4l2 -i /dev/video0 -vf "scale=320:240" ~/Videos/webcam_$(date +%Y%m%d_%H%M%S).mp4
```
*Плюс: параллельная запись. Минус: нужно синхронизировать два видео в редакторе.*
