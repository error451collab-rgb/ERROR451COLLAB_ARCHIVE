## 1. Телефон Tecno Spark 2022: сброс пароля и обход FRP

Ситуация классическая: девочка забыла пароль, а после сброса телефон упрется в **Google FRP (Factory Reset Protection)** — защиту, которая требует ввести последний синхронизированный Google-аккаунт [citation:2][citation:5]. Без него телефон — кирпич.

Вот что можно сделать.

### Сброс пароля экрана (если телефон заблокирован)

Сначала нужно сбросить сам пароль. Для Tecno Spark работает комбинация:

1. Выключи телефон.
2. Зажми одновременно **кнопку питания и кнопку увеличения громкости** (на некоторых моделях — уменьшения) [citation:10].
3. Когда появится логотип Tecno, отпусти кнопки.
4. В меню **Recovery Mode** (управляется кнопками громкости, выбор — кнопкой питания) выбери **Wipe data/factory reset** [citation:2][citation:10].
5. Подтверди сброс.

⚠️ **Важно:** После этого телефон запросит Google-аккаунт, который был привязан до сброса [citation:2]. Это и есть FRP.

### Обход FRP (если девочка не помнит пароль от Google)

Есть два пути.

**Путь А — без компьютера (сложный, но бесплатный):**

Метод через Talkback и обходные меню работает на многих Tecno [citation:1][citation:5]:

- На экране приветствия после сброса нажми три раза на кнопку «Домой» (или Home), чтобы включить Talkback.
- Зайди в Настройки Talkback → Поиск → введи «Getting started with Talkback».
- Запусти видео, нажми на три точки → Поделиться → Google Plus.
- Дальше нужно выйти в браузер, найти строку поиска, ввести `settings`, перейти в Системные настройки → Сброс → Сброс данных.
- После повторного сброса телефон может позволить ввести **новый** Google-аккаунт [citation:5].

Метод капризный, на разных версиях Android может не сработать.

**Путь Б — с компьютером (надежнее всего):**

Использовать программу **Wondershare Dr.Fone** — у нее есть специальная функция «Remove Google FRP Lock» для Tecno/Infinix/itel [citation:1][citation:9].

- Скачиваешь на свой Acer (с пиратской Windows, но это не помеха).
- Устанавливаешь, запускаешь, выбираешь **Screen Unlock (Android) → Remove Google FRP Lock → TECNO/Infinix/itel** [citation:9].
- Программа сама скачает нужный драйвер и проведет через процесс [citation:9][citation:13].
- Телефон перезагрузится без привязки к старому аккаунту.

**Еще вариант:** Если на телефоне включена отладка по USB, можно попробовать сброс через ADB-команды с компьютера [citation:6][citation:14]. Но это сложнее и требует навыков.

**Мой совет:** Начни с метода через Talkback — если прокатит, ты герой. Если нет — ставь Dr.Fone. Время — деньги, а нервотрепка с этими APK-обходниками того не стоит.

- **Масло в редукторе:** Проверь на эмульсию (белая пена — значит, вода попала, нужна замена сальников) [citation:4].

**Важно:** Если мотор **четырехтактный**, масло заливается в картер, а не в бензин! Не дай себя развести на смесь масла с топливом — это убьет двигатель [citation:12].

### 🎯 Новый подход: Форсированный обход через фрагментацию

Текущий режим (`--dns-addr 8.8.8.8`) чинит DNS, но не маскирует сам трафик. Нужно включить **фрагментацию пакетов** — это когда GoodbyeDPI разбивает пакеты на мелкие куски, чтобы цензор не мог понять, что это за трафик.

#### 1. Подготовка загрузочной флешки

    *   Рядом с "Метод загрузки" нажми "ВЫБРАТЬ" и укажи путь к скачанному ISO-образу Windows 10.
    *   Остальные настройки можешь оставить по умолчанию. Нажми "Старт" и дождись завершения записи.

#### 2. Подготовка места для новой системы
Нам нужно освободить место на жестком диске для установки Windows 10. Сделаем это, не трогая твою текущую Windows 7.

*   Нажми сочетание клавиш **Win + R**, введи `diskmgmt.msc` и нажми Enter. Откроется "Управление дисками".
*   Найди свой основной диск (обычно это диск C:). Он может быть разбит на разделы. Нам нужно **сжать** один из них, чтобы получить неразмеченное пространство.
*   Кликни правой кнопкой мыши по разделу, где есть свободное место (например, по диску C: или D:), и выбери **"Сжать том"** .
*   В поле "Размер сжимаемого пространства в МБ" укажи желаемый размер для Windows 10. Чтобы система работала нормально, лучше выделить **не менее 50 ГБ** (это примерно 51200 МБ). Нажми "Сжать".
*   Через некоторое время в списке дисков появится новый кусок неразмеченного пространства. Это и есть место для нашей новой системы [citation:1][citation:4][citation:7].

#### 3. Установка Windows 10
*   Вставь подготовленную загрузочную флешку в ноутбук и перезагрузи его.
*   При включении нажми клавишу для входа в Boot Menu. Обычно это **F12**, **Esc** или **F10** (зависит от модели). На экране должна появиться подсказка.
*   В Boot Menu выбери загрузку с USB-флешки.
*   Начнется установка Windows 10. Когда дойдешь до шага с выбором типа установки, выбери **"Выборочная: только установка Windows (для опытных пользователей)"** [citation:7].
*   На экране выбора раздела для установки выбери то самое неразмеченное пространство, которое мы создали ранее. Нажми "Далее". Установка продолжится автоматически [citation:1][citation:7].

После установки ноутбук перезагрузится. Теперь при включении ты будешь видеть меню с выбором операционной системы: **Windows 10** и **Windows 7**. Ты сможешь загружать ту, которая нужна в данный момент [citation:4][citation:7][citation:10].
