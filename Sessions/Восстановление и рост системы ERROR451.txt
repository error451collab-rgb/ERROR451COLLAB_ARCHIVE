### Этап 1: Подготовка «Хранилища Зерна» (старого диска)

    ```bash

    # Проверим здоровье диска (если это HDD/SSD)

    ```
2.  **Разметка (если нужно):** Если диск чистый или данные не нужны, создадим на нем раздел для снимков. Лучше отформатировать его в `ext4` или `btrfs` (последнее — родная файловая система для снимков).
    ```bash

    sudo fdisk /dev/sdX  # Консольный инструмент. Создаем один раздел на весь диск.
    sudo mkfs.ext4 /dev/sdX1  # Форматируем раздел в ext4.
    ```
3.  **Монтирование:** Создадим точку монтирования и подключим диск.
    ```bash

    # Чтобы монтировать автоматически при загрузке, добавим запись в /etc/fstab
    sudo blkid /dev/sdX1  # Узнаем UUID раздела
    sudo nano /etc/fstab  # Добавим строку: UUID=ВАШ_UUID /mnt/grain_store ext4 defaults 0 2
    ```
