### Для Ethernet:
```bash

sudo ip route add default via 192.168.1.1
```

### Для Wi-Fi:
```bash
# Поиск сетей
nmcli dev wifi list

# Подключение
nmcli dev wifi connect "SSID" password "пароль"
```

## Шаг 5: Постоянная настройка через Netplan (Ubuntu 22.04)

```bash
# Отредактируйте конфигурацию
sudo nano /etc/netplan/00-installer-config.yaml
```

Пример конфигурации для DHCP:
```yaml
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: true
```

Пример статической конфигурации:
```yaml
network:
  version: 2
  ethernets:
    eth0:
      addresses:
        - 192.168.1.100/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]
```

Примените изменения:
```bash
sudo netplan apply
```

## 📝 **Как прописать оба DNS сразу:**

### **Способ 1: Через графический интерфейс (рекомендую для новичка)**

1. **Откройте настройки сети:**
   - Нажмите на значок сети (правый верхний угол)
   - Выберите **"Настройки сети"** или **"Параметры сети"**
   - Или откройте **"Настройки"** → **"Сеть"**

2. **Настройте подключение:**
   - Нажмите на ваше подключение (Wi-Fi или Ethernet)
   - Нажмите **шестерёнку** ⚙️
   - Перейдите на вкладку **IPv4** или **IPv6** (чаще IPv4)

3. **Введите DNS-серверы:**
   - Метод: **"Вручную"** или **"Только автоматические адреса (DHCP) адреса"**
   - В поле **DNS** введите через запятую:

```
8.8.8.8, 8.8.4.4, 1.1.1.1, 1.0.0.1
```

   Это будет 4 DNS-сервера: два от Google и два от CloudFlare.

4. **Сохраните:**
   - Нажмите **"Применить"**
   - Может потребоваться переподключиться к сети

### **Способ 2: Через терминал (команды)**

```bash
# 1. Отредактируем конфигурацию (для Ubuntu 22.04)
sudo nano /etc/netplan/01-network-manager-all.yaml
```

Добавьте или измените раздел с DNS:

```yaml
network:
  version: 2
  renderer: NetworkManager
  ethernets:
    ваше_устройство:
      dhcp4: true
      nameservers:
        addresses: [8.8.8.8, 8.8.4.4, 1.1.1.1, 1.0.0.1]
```

**Если не хотите редактировать файлы**, есть простая команда:

```bash
# Установить DNS временно (до перезагрузки)
echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf
echo "nameserver 8.8.4.4" | sudo tee -a /etc/resolv.conf
echo "nameserver 1.1.1.1" | sudo tee -a /etc/resolv.conf
echo "nameserver 1.0.0.1" | sudo tee -a /etc/resolv.conf
```

### **Способ 3: Чрез NetworkManager (команды)**

```bash
# Показать текущие подключения
nmcli connection show

# Изменить DNS для вашего подключения (замените YOUR-CONNECTION-NAME)
sudo nmcli connection modify "YOUR-CONNECTION-NAME" ipv4.dns "8.8.8.8 8.8.4.4 1.1.1.1 1.0.0.1"
sudo nmcli connection up "YOUR-CONNECTION-NAME"
```
