#### 1. Подключение смартфона к компьютеру:
Подключите ваш смартфон к компьютеру через кабель USB или создайте точку доступа Wi-Fi на смартфоне и подключитесь к ней с компьютера.

#### 2. Изменение значения TTL:
Многие операторы мобильной связи используют проверку TTL (Time To Live) пакетов для обнаружения устройств, подключающихся через телефонную точку доступа. Обычно TTL пакета уменьшается на единицу при прохождении каждого сетевого узла. Поэтому для обхода ограничения нужно изменить значение TTL таким образом, чтобы оно отличалось от исходного на одну единицу.

Откройте терминал и выполните команды от имени суперпользователя (`sudo`):

```bash
# Создаем файл скрипта для установки фиксированного TTL
sudo nano /etc/iptables.rules

# Вставляем следующий код в созданный файл:
*filter
:INPUT ACCEPT [0:0]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [0:0]
COMMIT
*mangle
-A POSTROUTING -o wlan0 -j TTL --ttl-set 65 # устанавливаем TTL = 65 для адаптера wlan0
COMMIT
```

Затем примените правила `iptables`, выполнив команду:

```bash
sudo iptables-restore < /etc/iptables.rules
```

Также убедитесь, что правило сохраняется автоматически при загрузке системы:

```bash
sudo systemctl enable netfilter-persistent.service
sudo systemctl start netfilter-persistent.service

4. Примените новые правила:

      sudo iptables-restore < /etc/iptables.rules

      sudo apt install iptables-persistent
   sudo dpkg-reconfigure iptables-persistent

### 🖥️ **Легенда: Решение проблемы с загрузчиком**
Ошибка «no bootable device» и странная разметка (`efi` вместо `ext4`) говорят о двух вещах:
1.  **Загрузчик (GRUB) установился не туда** — возможно, на флешку.
2.  **Ты создал раздел с файловой системой EFI, а не корневой (`/`) раздел.**

**Нужно вручную создать правильную разметку.** Вот схема для **Legacy BIOS (не UEFI)**, который, скорее всего, на Легенде:

| Точка монтирования | Файловая система | Размер         | Комментарий                                                                 |
| :----------------- | :--------------- | :------------- | :-------------------------------------------------------------------------- |
| `/`                | `ext4`           | 20-40 ГБ       | Корневой раздел для системы. Укажи здесь **`/`**.                           |
| `swap`             | `swap`           | 2-4 ГБ         | Раздел подкачки.                                                            |
| `/mnt/grain_store` | `ext4`           | Оставшееся место | **БЕЗ ФОРМАТИРОВАНИЯ!** Только точку монтирования. Используй существующий. |

**Действия:**
1.  В программе разметки выбери **«Создать новую таблицу разделов»**. Это сотрёт всё на диске, но очистит путаницу.
2.  Последовательно создай:
    *   **Корневой раздел (`/`)**: ФС `ext4`, размер ~30 ГБ.
    *   **Раздел подкачки (`swap`)**: Укажи «Использовать как: swap».
    *   **Раздел с данными**: Выбери существующий раздел (`/dev/sdb2` или подобный). **Сними галочку «форматировать»** и укажи точку монтирования **`/mnt/grain_store`**.
3.  **Ключевой момент:** Внизу окна установщика есть выбор **«Устройство для установки загрузчика»**. **Выбери основной диск** (например, `/dev/sda`), а **НЕ** раздел (не `/dev/sda1`).

**Новая, правильная разметка для BIOS (на весь диск):**
| Точка монтирования | Тип           | Размер (пример) | Комментарий                                      |
| :----------------- | :------------ | :-------------- | :----------------------------------------------- |
| `/`                | `ext4`        | 30-40 ГБ        | **Корневой раздел для системы.**                 |
| `swap`             | `swap`        | 4-8 ГБ          | Раздел подкачки.                                 |
| `/mnt/grain_store` | `ext4`        | Весь остаток     | **БЕЗ ФОРМАТИРОВАНИЯ!** Смонтировать существующий. |

**Твои действия в установщике:**
1.  В ручной разметке выбери каждый раздел (`/dev/sda1`, `/dev/sda2` и т.д.) и нажми **"Удалить"**. В итоге останется одно **"Свободное место"** на весь диск.
2.  **Создай новые разделы по схеме выше.**
3.  **Ключевой момент (после создания разделов):** Внизу окна есть **"Устройство для установки загрузчика"**. **Выбери `/dev/sda` (целый диск), а не раздел вроде `/dev/sda1`.**

Это даст 99% шансов на успешную загрузку.

## **📜 ЧАСТЬ 1: ДЛЯ СТАРОГО BIOS (или UEFI в режиме Legacy)**

**Цель:** Создать простые, понятные разделы, которые гарантированно загрузятся.

### **Шаг 1: Очистка диска (если это новая установка)**
1.  В таблице разметки выберите диск (например, `/dev/sda`).
2.  Нажмите **«Новая таблица разделов»** и подтвердите. Все старые разделы будут удалены.

### **Шаг 2: Создание корневого раздела (обязательно)**
1.  Выделите строку **«свободное место»** и нажмите **«+»**.
2.  В диалоговом окне укажите:
    *   **Размер:** `30000` МБ (30 ГБ — хороший минимум для системы).
    *   **Тип нового раздела:** **`Основной`**.
    *   **Местоположение:** **`Начало этого пространства`**.
    *   **Использовать как:** **`Файловая система Ext4`**.
    *   **Точка монтирования:** **`/`** (корневой раздел).
3.  Нажмите **«ОК»**.

### **Шаг 3: Создание раздела подкачки (рекомендуется)**
1.  Выделите оставшееся **«свободное место»**, нажмите **«+»**.
2.  Укажите:
    *   **Размер:** `4096` МБ (4 ГБ) или, если ОЗУ мало (2 ГБ), `8192` МБ (8 ГБ).
    *   **Тип:** `Основной` или `Логический` (разницы для BIOS нет).
    *   **Местоположение:** `Начало`.
    *   **Использовать как:** **`Раздел подкачки`**.
3.  Нажмите **«ОК»**.

### **Шаг 4: Создание раздела для данных (опционально, но рекомендуется)**
1.  Выделите оставшееся **«свободное место»**, нажмите **«+»**.
2.  Укажите:
    *   **Размер:** *Оставшееся место* (оставьте значение по умолчанию).
    *   **Тип:** `Логический` (так проще для организации, если разделов много).
    *   **Местоположение:** `Начало`.
    *   **Использовать как:** `Файловая система Ext4`.
    *   **Точка монтирования:** **`/home`** или **`/mnt/data`** (второй вариант удобен, если будете переустанавливать систему — данные останутся в безопасности).
3.  Нажмите **«ОК»**.

### **КЛЮЧЕВОЙ ФИНАЛЬНЫЙ ШАГ ДЛЯ BIOS**
В **нижней части окна** установщика найдите выпадающий список:
*   **«Устройство для установки загрузчика»** (или Bootloader device).
*   **ВЫБЕРИТЕ ЦЕЛИКОМ ДИСК**, например **`/dev/sda`** (а **НЕ** раздел `/dev/sda1`!).
*   Это гарантирует, что загрузчик (GRUB) запишется в **MBR** диска.

## **💾 ЧАСТЬ 2: ДЛЯ СОВРЕМЕННОГО UEFI**

**Цель:** Создать обязательный системный раздел **EFI** для загрузки.

### **Шаг 1: Очистка диска**
Аналогично BIOS.

### **Шаг 2: Создание системного раздела EFI (ОБЯЗАТЕЛЬНО)**
1.  Выделите **«свободное место»**, нажмите **«+»**.
2.  Укажите:
    *   **Размер:** `512` МБ (минимум 100 МБ, но 512 — с запасом).
    *   **Тип:** `Основной`.
    *   **Местоположение:** `Начало`.
    *   **Использовать как:** **`Системный раздел EFI`**. Этот пункт появится только если установщик определил режим UEFI.
3.  Нажмите **«ОК»**.

### **Шаг 3: Создание корневого раздела `/`**
Повторите **Шаг 2 из части 1** (BIOS), создав раздел 30-100 ГБ для системы (`/`).

### **Шаг 4: Создание раздела подкачки и домашнего раздела**
Повторите **Шаги 3 и 4 из части 1** (BIOS).

### **КЛЮЧЕВОЙ ФИНАЛЬНЫЙ ШАГ ДЛЯ UEFI**
В списке **«Устройство для установки загрузчика»** выберите тот самый **EFI-раздел**, который вы только что создали (например, `/dev/sda1`). Установщик сам поместит туда загрузчик.

## **❗ ВАЖНЫЕ ПРИНЦИПЫ**
*   **«Основной» vs «Логический»:** На одном диске может быть не более **4-х основных** разделов. Если нужно больше, один из основных нужно сделать **«Расширенным»**, а внутри него создавать **логические**. Для простой схемы (корень, подкачка, home) хватит основных.
*   **«Начало» vs «Конец»:** Всегда выбирайте **«Начало»** для оптимальной скорости доступа к диску.
*   **Проверка:** Перед нажатием «Продолжить» убедитесь, что в таблице есть раздел с точкой монтирования **`/`**, а внизу окна правильно выбрано **устройство для загрузчика**.

### 📝 **Как проверить (пошагово)**

**ШАГ 1: Найдите оригинальный файл образа (`.iso`) и официальную контрольную сумму**
1.  **Найдите файл `.iso`**, который вы скачивали (например, `linuxmint-22.1-cinnamon-64bit.iso`). Он может быть в папке `~/Загрузки`.
2.  **Найдите ОФИЦИАЛЬНУЮ контрольную сумму** для этой версии на сайте Linux Mint. Обычно она находится на той же странице загрузки, в разделе "Checksums" или "SHA256". Выглядит как длинная строка из букв и цифр. **Скопируйте её**.

**ШАГ 2: Вычислите хеш вашего файла в терминале**
Откройте терминал в папке, где лежит ваш `.iso` файл (например, `cd ~/Загрузки`) и выполните команду:

```bash
sha256sum linuxmint-22.1-cinnamon-64bit.iso
```
(Замените имя файла на ваше).

Команда выдаст строчку вида:
`459e...a752 linuxmint-22.1-cinnamon-64bit.iso`

**ШАГ 3: Сравните две строки**
Внимательно сравните строку из терминала с **официальной строкой с сайта**.
*   **Если они идентичны** — образ скачан верно. Проблема может быть в записи на флешку или в железе.
*   **Если они отличаются даже на один символ** — образ битый. Его нужно **скачать заново** (желательно через другой браузер или с другим интернет-соединением) и повторить проверку.

### 💡 **Что делать, если оригинальный `.iso` файл уже удалён?**
Если осталась только флешка, а файла нет, есть **косвенный способ**:
1.  Скачайте **точно такую же версию** образа с официального сайта заново (например, `linuxmint-22.1-cinnamon-64bit.iso`).
2.  Проверьте её контрольную сумму по инструкции выше, чтобы убедиться, что новый файл цел.
3.  **Перезапишите флешку** этим новым, проверенным образом (используйте `balenaEtcher` или `dd`). Старая запись считается ненадёжной.

```bash

cd ~/Загрузки

# Вычислите его SHA256

# Сравните вывод с официальной суммой. Можно даже автоматически:
echo "ОФИЦИАЛЬНАЯ_СТРОКА_С_САЙТА имя_вашего_файла.iso" | sha256sum -c
```
