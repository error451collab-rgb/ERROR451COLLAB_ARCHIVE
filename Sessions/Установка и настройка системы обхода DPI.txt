#### **D. TOR Bridges (obfs4, meek)**
Специальные мосты Tor, которые маскируются под обычный трафик.

#### **E. GOST / Brook**
Русскоязычные инструменты с маскировкой.

### **C. АЛЬТЕРНАТИВА: SMART PROXY PAC-ФАЙЛ**
Создай автоматический конфиг:

```bash
# Создаём PAC-файл
cat > ~/proxy.pac << 'EOF'
function FindProxyForURL(url, host) {
    // Сайты которые идут через прокси
    var proxy_sites = [
        "youtube.com", "youtu.be", "googlevideo.com",
        "reddit.com", "twitter.com", "threads.net",
        "bbc.com", "piped.video", "yewtu.be"
    ];
    
    // Проверяем каждый домен
    for (var i = 0; i < proxy_sites.length; i++) {
        if (shExpMatch(host, "*" + proxy_sites[i])) {
            return "SOCKS5 127.0.0.1:1080; SOCKS 127.0.0.1:1080";
        }
    }
    
    // Все остальные сайты напрямую
    return "DIRECT";
}
EOF
```

## **ШАГ 3: ВОССТАНОВЛЕНИЕ НАСТРОЕК FIREFOX**

**Задача:** Вернуть Firefox к настройкам "без прокси", чтобы он не пытался подключаться через несуществующий прокси.

**Выполни:**
```bash
# 1. Закрой Firefox полностью (если открыт)
pkill firefox

# 2. Создаём скрипт для сброса прокси-настроек Firefox
cat > ~/reset_firefox_proxy.sh << 'EOF'
#!/bin/bash
# Находим файл настроек Firefox
PREFS_FILE=$(find ~/.mozilla/firefox -name "prefs.js" -type f | head -1)

if [ -f "$PREFS_FILE" ]; then
    echo "Найден файл настроек: $PREFS_FILE"
    # Создаём резервную копию
    BACKUP="${PREFS_FILE}.backup.$(date +%s)"
    cp "$PREFS_FILE" "$BACKUP"
    echo "Создан backup: $BACKUP"
    
    # Удаляем ВСЕ proxy-настройки
    grep -v 'user_pref("network.proxy' "$PREFS_FILE" > "${PREFS_FILE}.tmp"
    mv "${PREFS_FILE}.tmp" "$PREFS_FILE"
    
    # Добавляем настройку "без прокси"
    echo 'user_pref("network.proxy.type", 0);' >> "$PREFS_FILE"
    
    echo "✅ Настройки Firefox сброшены. Прокси отключен."
else
    echo "❌ Файл настроек Firefox не найден"
fi
EOF

# 3. Делаем скрипт исполняемым и запускаем
chmod +x ~/reset_firefox_proxy.sh
~/reset_firefox_proxy.sh

# 4. Проверяем результат
echo "Проверь, что вывел скрипт выше"
```
