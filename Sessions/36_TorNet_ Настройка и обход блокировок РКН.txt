---

### 1. **Быстрый обход (VPN поверх Tor):**
```bash
# 1) Запустить VPN (например, ProtonVPN)
protonvpn-cli c -f

# 2) Запустить TorNet поверх VPN
TorNet --start

# 3) Проверить цепочку: VPN → Tor → Интернет
curl --socks5 localhost:9050 https://check.torproject.org
```

---

### 2. **Специальные мосты (если VPN недоступен):**
```bash
# В файле /etc/tor/torrc добавить мосты (получить на bridges.torproject.org):
UseBridges 1
ClientTransportPlugin obfs4 exec /usr/bin/obfs4proxy
Bridge obfs4 185.220.100.254:443 cert=... iat-mode=0
# После:
systemctl restart tor
```

---

### 3. **Xray/Shadowsocks поверх Tor (для сложных блокировок):**
```bash
# Установка Xray + настройка туннеля до внешнего сервера
# (сервер за пределами РФ должен быть предварительно поднят)
xray run -config /etc/xray/config_tunnel.json
```

### Вариант A: Через iptables (временный, до перезагрузки)
```bash
# Блокируем исходящий трафик Tor
sudo iptables -A OUTPUT -o wlp6s0 -p tcp --dport 9001 -j DROP
sudo iptables -A OUTPUT -o wlp6s0 -p tcp --dport 9030 -j DROP
sudo iptables -A OUTPUT -o wlp6s0 -p tcp --dport 9050:9051 -j DROP
```

### Вариант B: Постоянный запрет через systemd (service)
Создаём сервис, который применяет правила при загрузке:
```bash
sudo nano /etc/systemd/system/block-tor-ports.service
```

**Содержимое:**
```ini
[Unit]
Description=Block Tor ports on wlp6s0
After=network.target
Wants=network.target

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/sbin/iptables -A OUTPUT -o wlp6s0 -p tcp --dport 9001 -j DROP
ExecStart=/sbin/iptables -A OUTPUT -o wlp6s0 -p tcp --dport 9030 -j DROP
ExecStart=/sbin/iptables -A OUTPUT -o wlp6s0 -p tcp --dport 9050:9051 -j DROP
ExecStop=/sbin/iptables -D OUTPUT -o wlp6s0 -p tcp --dport 9001 -j DROP
ExecStop=/sbin/iptables -D OUTPUT -o wlp6s0 -p tcp --dport 9030 -j DROP
ExecStop=/sbin/iptables -D OUTPUT -o wlp6s0 -p tcp --dport 9050:9051 -j DROP

[Install]
WantedBy=multi-user.target
```

**Активируем:**
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now block-tor-ports.service
sudo systemctl status block-tor-ports
```

## Решение проблемы DNS:

### 1. **Использовать DNS-over-HTTPS через dnscrypt-proxy** (уже начали установку)
```bash
# Останавливаем systemd-resolved
sudo systemctl stop systemd-resolved
sudo systemctl disable systemd-resolved

# Настраиваем dnscrypt-proxy
sudo nano /etc/dnscrypt-proxy/dnscrypt-proxy.toml
```

**В файле ищем и меняем:**
```toml
# Строка ~30: server_names
server_names = ['cloudflare', 'quad9-doh-ip4-filter-pri']

# Строка ~60: listen_addresses
listen_addresses = ['127.0.0.1:53']

# Опционально: блокировка рекламы
blocked_query_response = 'refused'
```

**Перезапускаем:**
```bash
sudo systemctl restart dnscrypt-proxy
sudo systemctl status dnscrypt-proxy
```

### 2. **Проверяем работоспособность dnscrypt**
```bash
# Тестируем локальный DNS
dig @127.0.0.1 rutracker.org
nslookup rutracker.org 127.0.0.1
```

### 3. **Если dnscrypt не работает, используем простой обход:**
```bash
# Добавляем в /etc/hosts (временное решение)
sudo nano /etc/hosts

# Добавляем строку:
104.21.32.39 rutracker.org
```

### 4. **Быстрая проверка с использованием hosts**
```bash
# Тест с фиксированным IP

```

### 5. **Проверяем сетевую доступность IP**
```bash
ping -c 3 104.21.32.39
telnet 104.21.32.39 443
```

## Временное решение пока настраиваем dnscrypt:

```bash

```

### Альтернатива: **DNS через TCP** (менее часто блокируется)

## **ИНСТРУКЦИЯ: КАК СОХРАНИТЬ В PDF НА LINUX**

### **Способ 1: Через LibreOffice (рекомендую)**
```bash
# Устанавливаем если нет
sudo apt install libreoffice-writer

# Создаём документ
libreoffice --writer
```
**Внутри LibreOffice:**
1. Вставляешь текст бизнес-плана
2. **Файл → Экспорт в → Экспорт в PDF...**
3. Выбираешь параметры → **Экспорт**
4. Сохраняешь как `бизнес_план.pdf`

### **Способ 2: Через браузер (быстро)**
1. Открываешь этот текст в браузере
2. **Ctrl+P** (Печать)
3. В принтере выбираешь **"Сохранить как PDF"**
4. Сохраняешь

### **Способ 3: Командная строка**
```bash
# Устанавливаем pandoc и texlive
sudo apt install pandoc texlive-latex-base texlive-fonts-recommended

# Конвертируем текстовый файл в PDF
pandoc бизнес_план.txt -o бизнес_план.pdf
```
