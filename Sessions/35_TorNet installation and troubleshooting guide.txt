DeepSeek: Чтобы остановить вывод логов (запись в консоль) в текущем терминале, есть несколько способов:

## 🔇 **СПОСОБЫ ОСТАНОВКИ ВЫВОДА ЛОГОВ:**

### 1. **Закрыть текущий терминал** (самый простой)
Просто закрой окно терминала или введи:
```bash
exit
```
Но это остановит все процессы, запущенные в этой сессии (если они не запущены через `nohup` или `screen`).

### 2. **Приостановить процесс (пауза)**
Нажми `Ctrl + Z` — это приостановит текущий процесс и вернет управление терминалу.
Чтобы продолжить работу процесса в фоне:
```bash
bg
```
Чтобы вернуть процесс на передний план:
```bash
fg
```

### 3. **Перенаправить вывод в /dev/null** (для нового запуска)
Если запускаешь команду заново:
```bash
TorNet start_tor --interval 300 --count 0 > /dev/null 2>&1 &
```
- `> /dev/null` — перенаправляет стандартный вывод в никуда
- `2>&1` — перенаправляет ошибки туда же
- `&` — запуск в фоне

### 4. **Для уже запущенного процесса:**
Найди его PID:
```bash
ps aux | grep TorNet
```
И перенаправь вывод (если нужно):
```bash
# Не всегда работает для уже запущенных процессов
sudo strace -p [PID] -e write 2>&1 | grep "write"
```
Но проще перезапустить.

### 5. **Использовать screen/tmux** (рекомендуется для долгих процессов)
```bash
# Установить screen если нет
sudo apt install screen

# Создать новую сессию
screen -S tornet

# Запустить TorNet внутри screen
sudo TorNet start_tor --interval 300 --count 0

# Отключиться от screen (процесс продолжит работу)
Ctrl + A, затем D

# Вернуться к сессии
screen -r tornet

# Завершить сессию screen
exit
```

## 🛑 **ЕСЛИ ХОЧЕШЬ ОСТАНОВИТЬ САМ TORNET:**

```bash
# Способ 1 - через команду TorNet
TorNet stop_tor

# Способ 2 - через kill
ps aux | grep TorNet
kill [PID]

# Способ 3 - killall
pkill -f TorNet
pkill -f tor
```

## 📝 **РЕКОМЕНДАЦИЯ НА БУДУЩЕЕ:**

Для запуска TorNet **без логов в консоль**:
```bash
sudo TorNet start_tor --interval 300 --count 0 > /tmp/tornet.log 2>&1 &
```
Логи будут в файле `/tmp/tornet.log`, а консоль останется чистой.

## 🔄 **ПРАВИЛЬНАЯ ПЕРЕУСТАНОВКА TORNET:**

```bash
# 1. Удаляем старую установку
sudo rm -rf /usr/local/bin/TorNet
sudo rm -rf ~/TorNet

# 2. Клонируем заново
cd ~
git clone -b main https://github.com/leohab75/TorNet.git
cd TorNet

# 3. Смотрим что в install.sh
cat install.sh

# 4. Запускаем установку с правами
bash install.sh
```

## 🔧 **ЕСЛИ INSTALL.SH НЕ РАБОТАЕТ, УСТАНОВИМ ВРУЧНУЮ:**

```bash
# Создаем директории
sudo mkdir -p /usr/local/bin/TorNet

# Копируем файлы
sudo cp -r ~/TorNet/* /usr/local/bin/TorNet/

# Даем права
sudo chmod -R 755 /usr/local/bin/TorNet
sudo chown -R $USER:$USER /usr/local/bin/TorNet

# Создаем симлинк для команды TorNet
sudo ln -sf /usr/local/bin/TorNet/scripts/TorNet /usr/local/bin/tornet
```

## 📦 **УСТАНОВКА ЗАВИСИМОСТЕЙ ДЛЯ ЭТОЙ ВЕРСИИ:**

```bash
# Устанавливаем специфичные зависимости для этой версии
cd ~/TorNet

# Смотрим requirements если есть
ls -la requirements*.txt

# Устанавливаем зависимости
sudo pip3 install -r requirements.txt 2>/dev/null || echo "No requirements.txt"

# Устанавливаем основные модули
sudo pip3 install pystray psutil requests beautifulsoup4 lxml stem cryptography PySocks
```

## 🛠 **ИСПРАВЛЯЕМ ОШИБКИ КОНКРЕТНО ДЛЯ ЭТОЙ ВЕРСИИ:**

```bash
# Переходим в директорию TorNet
cd /usr/local/bin/TorNet

# Смотрим структуру
find . -type f -name "*.py" | head -20

# Проверяем есть ли tor-relay-scanner
ls -la scripts/tor/

# Создаем недостающие файлы если нужно
sudo mkdir -p scripts/tor/tor-relay-scanner/
sudo touch scripts/tor/bridges.conf
```

## 🚀 **АВТОМАТИЧЕСКИЙ ФИКС ДЛЯ TORNET ОТ leohab75:**

```bash
cat << 'EOF' > /tmp/fix_leohab_tornet.sh
#!/bin/bash
echo "Fixing leohab75 TorNet installation..."

# 1. Находим директорию TorNet
TORNET_DIR="/usr/local/bin/TorNet"
if [ ! -d "$TORNET_DIR" ]; then
    echo "TorNet not found in $TORNET_DIR"
    exit 1
fi

cd "$TORNET_DIR"

# 2. Создаем недостающие директории
mkdir -p scripts/tor/tor-relay-scanner/
mkdir -p scripts/torparse/tor_relay_scanner/

# 3. Создаем заглушку для tor-relay-scanner
cat << 'PYEOF' > scripts/tor/tor-relay-scanner/torparse.py
#!/usr/bin/env python3
import sys
print("tor-relay-scanner stub for leohab75/TorNet")
sys.exit(0)
PYEOF

chmod +x scripts/tor/tor-relay-scanner/torparse.py
ln -sf torparse.py scripts/tor/tor-relay-scanner/torparse.pyz

# 4. Создаем недостающие __main__.py
cat << 'PYEOF' > scripts/torparse/tor_relay_scanner/__main__.py
def main():
    return 0
if __name__ == "__main__":
    import sys
    sys.exit(main())
PYEOF

touch scripts/torparse/tor_relay_scanner/__init__.py

# 5. Создаем недостающие конфиги
touch scripts/tor/bridges.conf
touch scripts/tor/tor.log

echo "Fix applied!"
echo "Try running: sudo python3 $TORNET_DIR/scripts/TorNet start_tor --interval 300 --count 0"
EOF

chmod +x /tmp/fix_leohab_tornet.sh
sudo /tmp/fix_leohab_tornet.sh
```

## 🎯 **БЫСТРЫЙ ЗАПУСК ЕСЛИ НИЧЕГО НЕ ПОМОГАЕТ:**

```bash
# Просто запускаем Tor напрямую
sudo pkill -9 tor 2>/dev/null

# Создаем простой torrc
cat << 'EOF' > /tmp/torrc
SocksPort 9050
ControlPort 9051
Log notice file /tmp/tor.log
DataDirectory /tmp/tor-data
EOF

# Запускаем Tor
tor -f /tmp/torrc &

# Ждем
sleep 10

# Проверяем
curl --socks5-hostname 127.0.0.1:9050 https://check.torproject.org | grep -i "congratulations"
```

```bash
    echo -e "AUTHENTICATE\nSIGNAL NEWNYM" | nc 127.0.0.1 9051

    echo "Новый IP: $NEW_IP"
done
```

```bash
cat << 'EOF' > /tmp/restore_tornet.sh
#!/bin/bash
echo "=== Восстановление TorNet ==="

# 1. Убиваем все процессы
echo "Остановка старых процессов..."
sudo pkill -9 tor 2>/dev/null
sudo pkill -f "TorNet" 2>/dev/null
sudo pkill -f "tor-relay" 2>/dev/null
sleep 2

# 2. Проверяем наличие /usr/bin/TorNet
if [ -f "/usr/bin/TorNet" ]; then
    echo "Запуск через /usr/bin/TorNet..."
    bash /usr/bin/TorNet 'start_tor' 2>&1 | tail -20
else
    echo "/usr/bin/TorNet не найден, запуск напрямую..."
    tor --RunAsDaemon 1 --SocksPort 9050 --ControlPort 9051 --Log "notice file /tmp/tor_restore.log" &
fi

# 3. Ждём
echo "Ожидание 30 секунд..."
sleep 30

# 4. Проверка
echo "=== Проверка ==="
if netstat -tln | grep -q 9050; then
    echo "✓ Порт 9050 слушается"
    
    CHECK=$(curl -s --socks5-hostname 127.0.0.1:9050 https://check.torproject.org 2>/dev/null | grep -i congrat)
    if [ -n "$CHECK" ]; then
        echo "✓ Tor работает!"
        IP=$(curl -s --socks5-hostname 127.0.0.1:9050 https://ipinfo.io/ip 2>/dev/null)
        echo "Ваш IP через Tor: $IP"
    else
        echo "✗ Tor не отвечает"
        echo "Логи:"
        tail -20 /tmp/tor_restore.log 2>/dev/null || tail -20 /usr/local/bin/TorNet/scripts/tor/tor.log 2>/dev/null
    fi
else
    echo "✗ Порт 9050 не активен"
fi
EOF

chmod +x /tmp/restore_tornet.sh
sudo /tmp/restore_tornet.sh
```
